# Unturned服务器租用：从3人小队到20人社区服，配置选型、内存需求与开服流程一次说清

搜"Unturned服务器租用"的人，问题通常很具体：我和三个朋友想玩，买最便宜的那档行不行？20 人的 PVP 服要多少内存？租来的服务器怎么让朋友在游戏里搜到？

Unturned 的专用服务端确实不吃配置，但"不吃配置"和"随便买一台就行"是两件事。玩家数、地图大小、有没有上插件，会把实际占用拉开好几倍。这篇按"先算需求、再选套餐、最后开服"的顺序来说。

## 先算需求：Unturned 到底吃多少内存

原版服务端在新开的世界里空载大约占 400–600MB。这个数字很容易让人误判——1GB 看起来够，实际上玩家一进来，服务器要开始记录每个人的背包状态、建筑数据、僵尸模拟和位置同步，占用会往上爬。

按玩家数估算原版服的内存需求：

| 同时在线人数 | 建议内存（原版） |
| --- | --- |
| 1–8 人 | 2GB |
| 8–16 人 | 3GB |
| 16–24 人 | 4GB |
| 24 人以上 | 5–6GB |

Unturned 服务端的默认玩家上限就是 8，这也是 2GB 能当"起步档"的原因。如果你在 Commands.dat 里把 `maxplayers` 改大了，内存要提前加上去，别等玩家开始反馈卡顿再回头升级。

**地图的影响主要在启动阶段。** PEI、Yukon、Washington 属于轻量图；Russia、Germany、Hawaii 明显更重，首次启动更慢、吃内存更多。有个反直觉的点：地图大不等于跑起来更卡。玩家在 Russia 上分散得开，同一区域内的实体密度反而比挤在 PEI 上低。地图大小是启动成本，玩家聚集密度才是运行成本。

**插件和内容 mod 是内存增长最快的地方。** 内容型 mod 包单个通常在 50–150MB 区间，装五六个就得按 GB 级往上加。RocketMod 和 OpenMod 框架本身各约 100–200MB 的开销，真正吃内存的是压在上面的东西——经济系统、商店、传送、Discord 通知这类插件叠起来，配置和纯原版完全不是一回事。经济类插件还会随存档时间慢慢变胖。

## 租还是用自己电脑开？

Unturned 官方服务端的最低要求只是 2.4GHz 双核，理论上你家电脑就能跑。真正劝退的是另外三件事：

- 家用宽带的上行带宽和稳定性撑不住多人同时在线，尤其玩 PVP 的时候；
- 大部分家庭网络没有公网 IP，光端口转发就能折腾掉一晚上；
- 你的电脑一关机，服务器就没了。

如果只是偶尔和两三个朋友进来看一眼，本地开完全够。只要涉及"朋友随时能进来"，租一台常年在线的服务器基本是唯一省心方案。

## 计费方式：先决定按月包还是按 CPU 用量付

这一步比选 CPU 型号更影响你的实际花费。以雨云的游戏云为例，它提供固定计费和动态计费两种模式。

固定计费就是传统的月租一口价，不额外收费，适合持续运行。

动态计费的规则是：CPU 使用率基准值 20%，低于 20% 算不耗电；超出部分按"CPU 电量"日结。电量单价按机型区分：

- 2666v3 / 8259cl 机型：0.0005 元/电量
- 6146 / 8275cl 机型：0.0006 元/电量
- 5900X / 7A23 机型：0.0008 元/电量
- 9950X / 7950X / 13900K / 14900K 等机型：0.001 元/电量

官方给过一个换算例子（以 5900X 双核为例）：1 个 CPU 电量 = 30% 使用率持续 1 分钟 = 0.0008 元；1 元约等于 1200 个电量，也就是约 30% CPU 跑 24 小时，或者 70% CPU 跑 4 小时。系统每天还会按核心数赠送一定的免费电量，用不完的可以叠加到第二天。

翻译成人话：

> 每天开服两小时以上、或者要长时间挂机跑世界模拟，选固定计费；只有晚上断断续续玩一两个小时，动态计费更省。

两种模式随时可以互相切换，配置也能升降级，所以第一台买保守一点问题不大。

## 在雨云上开 Unturned 服，具体怎么走

先说一个容易踩的坑：雨云的游戏面板目前一键开服支持的是 Minecraft Java 版、Minecraft 基岩版、泰拉瑞亚、饥荒，**Unturned 不在这个列表里**。所以你要么买游戏云 VPS 自己装，要么用面板提供的纯 Java / Linux（Docker）环境来跑。前者更自由。

**第一步：选机型。** Unturned 是典型的单核敏感型服务端，世界里所有的实体模拟、同步都压在主线程上。核心数够用就行，主频越高越舒服。这也是雨云游戏云主打高主频 CPU 的意义——14900K、13900KF、9950X、7950X 这类芯片单核强，对 MC 和 Unturned 这种场景比堆核数有用。其中 13900KF 和 14900KF 机型是屏蔽小核的纯大核方案，不会出现进程被调度到小核上导致掉帧的情况。

**第二步：装服务端。** 用 SteamCMD 拉取，Unturned 专用服务端的 App ID 是 1110390：


login anonymous
force_install_dir /your/path/unturned
app_update 1110390 validate


**第三步：开端口。** 需要放行 27015（Game Port）、27016（Query Port）、8766（Steam Server Port），协议是 TCP/UDP，按 27015–27017 整段放行最省事。如果买的是 NAT 机型，还要在控制台里做端口映射，把内网端口指到对外端口上。

**第四步：申请 GSLT。** 从 Unturned 3.21.31.0 版本起，专用服务端必须带 Steam Game Server Login Token（GSLT）才会出现在公开的 Internet 服务器列表里。没有 token 服务器照样能跑、别人也能用 IP 直连，但它不会出现在游戏内的服务器浏览器中，而且 join code 每次重启都会变。申请位置是 Steam 的游戏服务器账号管理页，App ID 填 304930（Unturned 本体 ID），你的 Steam 账号需要绑定手机号、没有被限制或封禁，并且拥有 Unturned（本体免费）。拿到 token 后写进 Commands.dat 的 `GSLT` 行，或者写进 Config.json 的 `Browser.Login_Token`，两个地方只填一处。

token 当密码看待，泄露了直接重新生成。

**第五步：管权限和存档。** 服务器目录下几个 .dat 文件就是权限系统的全部：Adminlist.dat 加管理员，Banned.dat 拉黑，Whitelist.dat 配白名单，每行一个 SteamID64。世界存档整个存在 `Servers/Default/Level/<地图名>/` 下面，换图、大版本更新之前把这个文件夹备份走，基本就丢不了东西。

## 按场景给一套具体建议

**3–6 人，原版 PEI 或者华盛顿，晚上玩两三个小时。** 2 核 4G 足够，带宽 10M 没问题，直接上动态计费。这个场景买高配纯属浪费，玩家进进出出的内存波动都在 2GB 以内。

**8–16 人，带一些武器/载具 mod，周末常开。** 4 核 8G 是舒服的位置，固定计费更划算，避免长时间运行的电量账单不可控。带宽建议 15M 起。

**16–24 人的社区服，装了 RocketMod 或 OpenMod 加一整套经济、商店、领地插件。** 6 核 12G 起步，内存按插件数量往上加。重点看 CPU 主频而不是核数，插件里有慢速 I/O 的时候加核数也救不了主线程。

**大型自定义地图（比如体积是 Russia 四倍的那种 Workshop 图）。** 这部分内存要在基础需求之外单独算，而且服务器首次启动会明显更久，别以为卡死了就重启。

如果一时拿不准，先买低一档、用 1 元试用确认实际表现，再决定要不要升配，比一步到位买贵了再退【尝试】省事得多。

## 常见问题

**一定要买独立公网 IP 吗？**
不一定。NAT 机型通过端口映射也能让玩家连进来，只是端口数量有限制，而且不能指定固定端口。NAT 机型通常提供 5 到 15 个端口映射名额，具体数字按节点和机型不同。想省心、要固定端口、或者以后想同时开多个服，再考虑加购独立 IP，价格按节点从 30 元/月到 60 元/月不等。

**服务器能连上，但游戏里搜不到？**
先检查 GSLT 有没有配置。这个几乎是最常见的原因。

**Windows 还是 Linux？**
Linux 更省内存，Ubuntu 或 Debian 都行，配一个面板管理起来也不难。Windows 的好处是远程桌面操作直观、方便挂一些只支持 Windows 的工具。

**中途能换配置吗？**
雨云游戏云支持随时升降配和切换计费模式，所以起步配置不用一次买到底。

**服务器会不会被打？**
雨云游戏云自带节点级高防，能力从 10G 到 200G 不等，具体看节点和机型。公开高防 IP 也可以单独加购。
